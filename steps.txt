step-1:  pip is working then  we will install uv 

open the terminal and write the command  'pip install uv' 

How to check the version: 

uv --version 

------------------------------------------

step-2: Apply this command on terminal 

uv init . 

Ye command kya karegi?
- Current folder ko UV Python project mein initialize karegi.
- Project configuration ke liye pyproject.toml file create karegi.
- Project ke liye initial files bhi create kar sakti hai.

------------------------------------

step-3 : Create a virtual Environment  
So for this , we wil oen the terminal and write 

uv venv 

Now we will activate the venv using this command 

.venv\Scripts\activate

---------------------------------

step-3: Now we will create 'requirements.txt' for installing libraries

----------------------

step-4: Now open the terminal and write command for install the libraries 

uv add -r requirements.txt 

Ye command kya karegi?
1. requirements.txt ko read karegi.
2. Usme listed libraries ko install karegi.
3. Project ki dependencies pyproject.toml mein manage karegi.
4. uv.lock file create/update karegi.
Example: NumPy, Pandas, Matplotlib etc. install ho jayengi.



install verification ke liye 
uv pip list run kro terminal pr


kabhi kabhi Windows + OneDrive ke file linking system mein dikkat hoti hai to .hamara project one drive mai to
UV libraries install karte waqt hardlink use karne ki koshish kar raha hai, lekin OneDrive ke cloud-managed files ke saath problem aa rahi hai.

Iska simple solution hai: UV ko hardlink ki jagah normal copy use karne ko bolna

terminal mai ye command run krenge

uv add -r requirements.txt --link-mode=copy

--link-mode=copy UV ko hardlink ke bajaye files ki normal copies banane ke liye kahega.



Libraries installation complete karne ki dobara koshish karega.
